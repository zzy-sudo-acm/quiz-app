# 刷题簿

静态 HTML/CSS/JavaScript 网站，部署于 GitHub Pages，无服务器后端。题库、错题、收藏和进度保存在浏览器本地，不跨设备同步。

## 题库

默认打开云计算选择题。右上角可切换题库，各题库单独保存答题进度、错题和收藏。

### 云计算

《学习通选择题》共 91 道单选，保留原题干和选项。

| 章节 | 题数 |
|---|---:|
| 云计算基础 | 15 |

| Docker | 40 |
| Spring Cloud 微服务 | 15 |

参考答案与解析根据课程复习资料和作答反馈整理。

## 使用

- 顺序练习、随机练习、错题本、收藏。
- 按章节或年份筛选，混合题型的题库也可按题型筛选。搜索覆盖题干及选项。
- 单选和多选均先选择，再提交；多选必须全部选对。
- 错题重新答对后自动移出；答题卡可直接跳转。
- “再练本组”只重置本轮，保留错题与收藏。
- 右上角“题库文件”可导入或导出 JSON。导入验证失败时保持当前题库。
- 当前题库及答题进度刷新后保留；清除浏览器站点数据会清除它们。
- 键盘 A–H 选项，题干或选项聚焦时 Enter 提交。按钮也可用 Tab/Enter 操作。

## 本地运行

```sh
python -m http.server 8765 --bind 127.0.0.1
```

访问 http://127.0.0.1:8765/ 。不要直接双击 index.html，浏览器会限制本地文件读取。

## 导入格式

兼容原项目 questions.json 数组结构，也接受包含 questions 数组的对象。

```json
[
  {
    "id": 201601,
    "type": "single",
    "question": "题干",
    "options": [
      {"key": "A", "text": "选项 A"},
      {"key": "B", "text": "选项 B"}
    ],
    "answer": ["A"],
    "year": "2016-2017",
    "number": 1,
    "page": 1,
    "source": "原始试卷.pdf",
    "answerSource": "参考答案来源",
    "explanation": "解析"
  }
]
```

`id` 为唯一正整数，`type` 为 `single` 或 `multiple`。每题有 2–8 个 A–H 选项，答案必须对应选项。单选有一个答案，多选至少两个。若题目标记为 `"answerStatus": "ungraded"`，使用 `"answer": []`。文件上限为 10 MB、10000 题。可选字段包括 `topic`、`year`、`note` 和 `references`。正文作为纯文本显示。

## GitHub Pages

沿用仓库的 `main` 分支根目录部署，无需安装依赖或构建。云计算题库位于 `cloud-questions.json`，马原题库位于 `questions.json`。PWA 首次成功联网加载后缓存页面和两个题库，更新后刷新页面取得新版资源。
